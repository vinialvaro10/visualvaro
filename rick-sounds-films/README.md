# Rick Sound Film's — site

Site estático (HTML + CSS + JS puro, sem build).

## Publicar no GitHub Pages
1. Suba o conteúdo desta pasta na raiz do repositório (o `index.html` precisa ficar na raiz).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main` / pasta `/ (root)`.
3. Aguarde 1–2 minutos e acesse o endereço mostrado.

## Hostinger
Suba `index.html`, a pasta `assets` e o `.htaccess` dentro de `public_html`.
